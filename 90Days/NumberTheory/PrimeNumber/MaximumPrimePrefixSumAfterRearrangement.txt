Problem: Maximum Prime Prefix Sums
Problem Statement:

You are given an array containing only 1 and 2.

You can rearrange the array in any order. Your task is to rearrange its elements such that the number of prime prefix sums is maximized.

Return the rearranged array.

Example 1:
Input: [1, 1, 2, 2]


Original prefix sums:
1
1 + 1 = 2
1 + 1 + 2 = 4
1 + 1 + 2 + 2 = 6


Prime prefix sums: 2

Count = 1

Rearranged array:
[2, 1, 2, 1]


Prefix sums:
2
2 + 1 = 3
2 + 1 + 2 = 5
2 + 1 + 2 + 1 = 6


Prime prefix sums: 2, 3, 5
Maximum count = 3
Example 2:
Input: [1, 1, 1]
Output: [1, 1, 1]

Prefix sums: 1, 2, 3
Prime prefix sums: 2, 3
Count = 2


Constraints
- Array contains only 1 and 2.
- You can rearrange elements but cannot add or remove any.
- Maximize the count of prime prefix sums.
